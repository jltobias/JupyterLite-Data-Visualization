# Historical cholera teaching data

Unchanged copies of `contents/cholera_deaths.csv`, `contents/pumps.csv` and the
repository `LICENSE` from **PHI-Case-Studies contributors**,
[Jupyterlite-1854-Cholera-Basic](https://github.com/PHI-Case-Studies/Jupyterlite-1854-Cholera-Basic/tree/476f6dd5a8430e6eb823e79614fda1d7e12a78fb).
The upstream GPL-3.0 license is retained here. Keep this notice, source link,
provenance record and license with redistributed copies and derivatives.

`provenance.json` records checksums and the pinned source revision. No upstream
notebook code, illustrations or video were copied into the new lesson.

The death table has 250 recorded locations totaling 489 deaths; the pump table
has eight records. One row is a location, not a person. These totals describe
this teaching dataset, not the full historical outbreak. The original
digitization and completeness have not been independently verified. `Street`
uses the source's names (including Broadwick Street); names are not model labels.

DBSCAN uses location coordinates only. The lesson does not estimate mortality
rates, identify water consumption, validate disease risk or infer causation.
Original CSV fields and counts remain separate from derived cluster labels.
