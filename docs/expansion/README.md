# Expansion design and evidence

Prepared 2026-10-28 for the requested expansion. These are research and design
artifacts; they do not claim that the proposed lessons or integrations already run.

The bounded [repository-inspired companion lessons](../../content/repository_examples/index.md)
are now implemented with original code, packaged evidence and an earthquake
story. Their [source input register](companion-source-evidence.md) and
[implementation specification](../../_bmad-output/implementation-artifacts/spec-repository-companion-notebooks.md)
are separate from the broader 100-method course and full GIS integration drafts.

- [Implementation specification](../../_bmad-output/implementation-artifacts/spec-100-elements-and-browser-geospatial-lab.md):
  proposed scope, constraints, tasks, and acceptance checks for approval.
- [100-element course matrix](100-element-coverage.md): a specific question,
  evidence source, visualization, activity, and limitation for every method.
- [Machine-readable matrix](100-element-coverage.json): stable course IDs and
  an explicit crosswalk to the current notebook.
- [Data source register](data-source-register.md): proposed extracts, provenance,
  access requirements, and attribution decisions still needed for each release.
- [Presentation and learning design](presentation-and-learning-design.md):
  teaching principles, case narratives, and the geospatial learning sequence.
- [PHI Case Studies review](phi-case-studies.md): pinned source review, licensing,
  historical versus simulated evidence, and adaptation candidates.
- [Related repository review](related-repositories.md): pinned review of the
  owner's geospatial, climate, health, and storymap projects.
- [Browser geospatial tool review](browser-geospatial-tools.md): practical
  boundaries between JupyterLite, browser applications, and native software.

The proposed course uses the 100 method names in Lengler and Eppler's source
framework, with spelling normalized and new course identifiers. It retains the
existing sampler as an appendix and documents changed names and classifications.
The eight additional legacy methods also receive expanded examples: 100 core
framework lessons plus eight appendix lessons, covering every current heading.
The navigator will be an original accessible index. The original periodic-table
artwork remains excluded; naming and citing methods does not establish permission
to redistribute the poster. See the [existing reuse evidence](../periodic-table-reuse-evidence.md).

Project licensing remains undecided, as the owner requested. A third-party
repository's software license does not automatically cover its datasets, slides,
images, articles, model weights, or linked services. No source repository assets,
presentation slides, or newly proposed datasets have been copied into the course
as part of this investigation.
