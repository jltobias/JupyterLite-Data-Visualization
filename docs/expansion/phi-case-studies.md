# PHI case studies: expansion research

Research date: 2026-10-28. Scope: nine candidate repositories in [PHI-Case-Studies](https://github.com/PHI-Case-Studies), inspected read-only using the connected GitHub API. Repository metadata, complete root listings, recursive trees, READMEs, actual available license texts, and selected notebook sources were checked. Large notebooks rejected by the fetch endpoint were successfully inspected through the connector's blob endpoint. No upstream code, datasets, images, audio, or notebooks were copied into this project. No notebooks were executed.

These sources offer reusable teaching ideas for public-health narratives, mapping, temporal comparison, and privacy. They do **not** establish coverage of all 100 visualization methods. Opportunities below are proposed course adaptations; GeoAI extensions are new work, not capabilities claimed for the source repositories. The project's license remains **undecided, for the user to choose**.

### Cholera: browser adaptation and basic case

Both versions contain two Folium notebooks, deaths/pumps CSVs, derived pickles, a historical map PDF, images, video, and audio. [Notebook 1](https://github.com/PHI-Case-Studies/1854-Cholera-Outbreak-London-Basic/blob/3d02bafc779c03d3195738b3d110e43a8184cfaf/NB01-Cholera-Case-Study-Folium-Map-Part-1.ipynb) reads local CSVs, builds point/circle maps, and cites historical accounts; [Notebook 2](https://github.com/PHI-Case-Studies/1854-Cholera-Outbreak-London-Basic/blob/3d02bafc779c03d3195738b3d110e43a8184cfaf/NB02-Cholera-Case-Study-Folium-Map-Part-2.ipynb) computes a death-weighted center. Neither inspected notebook establishes the digitized CSVs' original creator, transformation chain, or a separate data license. A historical event's age does not establish rights to modern digitization, scans, media, or basemap tiles.

Opportunity: spot maps, proportional symbols with correct area scaling, distance distributions, heatmaps, weighted centers, and explicit comparison of visual association with epidemiological evidence. Create original narrative text and separately sourced media. Preserve tile attribution and provider terms.

The [JupyterLite README](https://github.com/PHI-Case-Studies/Jupyterlite-1854-Cholera-Basic/blob/476f6dd5a8430e6eb823e79614fda1d7e12a78fb/README.md) links a hosted browser adaptation and its LICENSE is GPL-3.0; the basic version has Apache-2.0. They are not interchangeable licensing evidence. Browser operation was not verified: [the config](https://github.com/PHI-Case-Studies/Jupyterlite-1854-Cholera-Basic/blob/476f6dd5a8430e6eb823e79614fda1d7e12a78fb/jupyter_lite_config.json) names `content`, while the tree has `contents`, with flattened assets and notebook duplicates. Validate the served paths, imports, package installation, and iframe maps before treating it as a working integration model.

### MDR-TB, Thailand

The [README](https://github.com/PHI-Case-Studies/2005-MDR-TB-Outbreak-Thailand/blob/6d50f558cd39b40089cd3eea1fbc19425e5191d1/README.md) cites [Oeltmann et al. (2008), the report of the 2005 outbreak](https://doi.org/10.3201/eid1411.071629). [The introduction](https://github.com/PHI-Case-Studies/2005-MDR-TB-Outbreak-Thailand/blob/6d50f558cd39b40089cd3eea1fbc19425e5191d1/NB01-MDR-TB-Case-Study-Case-Intro.ipynb) explicitly describes a simulated investigation; exercise line listings and genotypes should not be represented as verified patient records. [World-TB notebook 1](https://github.com/PHI-Case-Studies/2005-MDR-TB-Outbreak-Thailand/blob/6d50f558cd39b40089cd3eea1fbc19425e5191d1/NB02-World-TB-Notebook-Part-1.ipynb) identifies WHO TB estimates and dictionary endpoints, World Bank indicators, dated 2019 snapshots, and World Bank licensing links.

Opportunity: progressive evidence, joins, missingness plots, epidemic curves, age distributions, bubble charts, and country trend maps. A new, explicitly synthetic contact network could support network methods; it is not supplied evidence of actual transmission. Retain indicator IDs, dates, uncertainty, and source metadata. Apache code does not license WHO reports, article PDFs, commercial audio, or all third-party data. [World Bank terms](https://datacatalog.worldbank.org/public-licenses) set CC BY 4.0 as the default for its own open data while allowing dataset-specific exceptions; verify each indicator's provider terms. The particular historical WHO exports' redistribution terms were not established.

### Botswana HIV: person, place, time

[Notebook 1](https://github.com/PHI-Case-Studies/2019-HIV-Prevalence-Botswana/blob/a1dfa7bda19b891a2453f8763c2ef116547494a8/HELINA-Workshop-2019-notebook-1.ipynb) extracts a population table from the 2011 Census PDF, a table from `BAIS2013.pdf`, and reads three UNAIDS CSVs; later notebooks create population pyramids, district choropleths, and trends. [District-shapefile metadata](https://github.com/PHI-Case-Studies/2019-HIV-Prevalence-Botswana/blob/a1dfa7bda19b891a2453f8763c2ef116547494a8/resources/BW_27Health_Districts.shp.xml) contains ArcGIS processing history but no useful ownership or reuse declaration; `resources/README.md` adds no provenance.

Opportunity: pyramids, grouped/dot charts, choropleths with matched denominators, time series with bounds, and synchronized person/place/time views. Pre-extract a documented small CSV for browser use rather than requiring PDF scraping. Keep 2011 population, 2013 survey, and 1990–2018 UNAIDS series temporally distinct. Apache code licensing does not settle rights in the government reports, boundaries, UNAIDS exports, or illustrations. UNAIDS' [general website usage statement](https://files.unaids.org/en/media/unaids/contentassets/documents/aboutunaids/workingwithunaids/UNAIDSPrivacyUseDataStatement_en.pdf) is not a blanket open-data grant; establish the specific export terms before redistribution.

### COVID-19 / NO₂ remote sensing

[The data-sources notebook](https://github.com/PHI-Case-Studies/2020-COVID19-NO2-Remote-Sensing/blob/7efbfb3dc5f01bdec1a31ffe996c6574eaaf8b80/NB01-Data-Sources.ipynb) downloads GADM 3.6 boundaries and a country-code table from the `lukes` GitHub repository; its tools process Sentinel-5P TROPOMI NO₂ swaths. [The README](https://github.com/PHI-Case-Studies/2020-COVID19-NO2-Remote-Sensing/blob/7efbfb3dc5f01bdec1a31ffe996c6574eaaf8b80/README.md) expects at least 16 GB RAM and 300 GB free disk, with a pipeline downloading about 105 GB. This is not a browser-sized workflow.

Opportunity: independently prepared, bounded regional/time samples, QA coverage, raster/color scales, paired maps, difference maps, distributions, and seasonal comparisons. A new GeoAI exercise could predict held-out spatial values and show residual/uncertainty maps; avoid interpreting lockdown coincidence as a causal health effect. Copernicus' [Sentinel data notice](https://cds.climate.copernicus.eu/licences/ec-sentinel) permits reuse and modification with the prescribed source/modified-data attribution. [Current GADM terms](https://gadm.org/license.html) restrict redistribution and commercial use without prior permission; historical 3.6-specific terms were not pinned. Do not assume the supplied GADM-derived pickles are generally open course data. Select independently licensed boundaries and record provenance. Article figures and provider imagery have their own rights.

### Ethical geospatial practice

[The README](https://github.com/PHI-Case-Studies/2023-Ethical-Practice-Geospatial-Data-Science/blob/9cd3b73ca2a3630335cd74753e38b819871e3974/README.md) frames the case as cholera geoprivacy. Notebook sources demonstrate donut masking and H3 hexagonal aggregation; the tree also includes evaluation helpers, building/street exercises, London 2018 wards, and Overpass-related assets. Source/data lineage and redistribution terms are incomplete.

Opportunity: displacement distributions, privacy/utility trade-offs, hexbin maps, aggregation sensitivity, and original-versus-masked comparison using reproducible synthetic points. A GeoAI extension could compare clustering or prediction before and after masking with spatial holdouts. Label masking as a technique to evaluate, not a privacy guarantee. Document projection/distance units and the mismatch between historical cases and modern wards. The absent license file and unsourced boundaries/buildings prevent assuming blanket reuse rights; use independently sourced, licensed boundaries or synthetic geometry for implementation.

## Course design implications

Use a few coherent case datasets across several method families, with a distinct analytical question for every method. Add clearly labeled synthetic data when a method requires structures absent from these cases, such as flows, hierarchies, or networks. The 100-method inventory still needs an explicit method-to-example coverage matrix.

For each later imported or newly generated asset, record source URL, version/date, creator, applicable license, attribution, transformation recipe, and sensitivity classification. Keep executable browser examples small and deterministic, with locally packaged CSV/GeoJSON or synthetic geometry once rights are established. GeoAI demonstrations should display validation and uncertainty and explain how spatial dependence affects evaluation.
