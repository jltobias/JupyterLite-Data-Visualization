# Proposed open-data source register

Primary sources checked 2026-10-28. This register specifies candidate extracts;
it is not a manifest of downloaded files. Release selection, schemas, checksums,
and exact citations must be recorded when actual files are acquired. The course
matrix uses the stable keys below. Default notebook execution uses local dated
extracts; refreshing data is a separate, explicit operation.

| Key | Proposed bounded extract and teaching use | Primary sources, access, and attribution | Interpretation and implementation limits |
| --- | --- | --- | --- |
| `acs` | 2024 ACS five-year county estimates for population, age, poverty, and vehicle access; selected California counties, plus state comparison. Include estimate and margin-of-error variables. | [2024 ACS API examples](https://api.census.gov/data/2024/acs/acs5/examples.html), [ACS documentation](https://www.census.gov/programs-surveys/acs/guidance.html). API queries now require a key. Use operator-side refresh credentials or documented public bulk downloads; publish no keys. Credit U.S. Census Bureau, ACS five-year release, table/variable IDs, geography, and retrieval date; retain source-specific terms. | Five-year period estimates are not a point-in-time census. Preserve GEOID strings, geography vintage, missing/suppression codes, denominators, and 90% margins of error. Align geography and periods before comparisons. |
| `places` | One pinned CDC PLACES county release: selected chronic-disease indicators, crude/age-adjusted estimates, confidence intervals, population, and measure definitions. | [CDC PLACES methodology](https://www.cdc.gov/places/methodology/index.html), [FAQs](https://www.cdc.gov/places/faqs/index.html), [data portal](https://www.cdc.gov/places/tools/data-portal.html). Use documented public CSV download with release ID and CDC's required citation. | These are modeled small-area estimates, not patient observations or diagnoses. Release year differs from source survey year. Age-adjusted estimates are available for counties/places, not all geographic products. CDC intervals and ACS margins use different conventions. |
| `epa` | A completed-year AirData annual AQI-by-county file and bounded daily monitor PM2.5 observations for selected California stations. Prefer 2024 for a fixed historical exercise. | [EPA AirData download files and documentation](https://aqs.epa.gov/aqsweb/airdata/download_files.html). Public pre-generated files avoid AQS API registration. Credit U.S. EPA AirData/AQS; retain file documentation, download date, pollutant IDs, units, and quality flags. | AQI is an index, not a concentration. Monitor coverage is uneven; a county average is not individual exposure. Preserve event flags, completeness, missing dates, and station histories. Never treat missing monitors as clean air. |
| `hrsa` | Dated HHS/HRSA health-center service-delivery sites and a county summary for the U.S. case. Add selected public shortage-area attributes only after reading their definitions. | [HRSA data downloads](https://data.hrsa.gov/data/download), [GeoCare Navigator data guide](https://data.hrsa.gov/DataDownload/GeoCareNavigator/AboutTheData.pdf). Use public downloads and their metadata; do not access staff-only systems. Credit HHS/HRSA and each named contributing provider. Determine terms per selected file. | Administrative sites and service-delivery sites differ. A mapped site does not measure capacity, appointment availability, quality, or travel time. Different layers have different update schedules. No individual health records. |
| `worldpop` | A small Kinshasa-area clip from a pinned DRC WorldPop population-count release, plus coarsened counts and grid metadata. Start with the documented v4.4 release rather than an unlabeled mirror. | [WorldPop FAQ and citation instructions](https://www.worldpop.org/faq/), [DRC v4.4 README](https://data.worldpop.org/repo/wopr/COD/population/v4.4/COD_population_v4_4_README.pdf). WorldPop specifies CC BY 4.0; record the exact release's authors, DOI, year, terms, and modifications. | Modeled population is not a census enumeration. Retain the reference year, model/version, count versus density, CRS, pixel area, nodata, and aggregation rules. Never infer migration by differencing incompatible releases. |
| `healthsites` | A dated facility snapshot for the same small DRC area, retained as a separately attributed database; aggregate approximate distance bands without implying service capacity. | [Healthsites primary wiki](https://github.com/healthsites/healthsites/wiki), [OpenStreetMap copyright and ODbL](https://www.openstreetmap.org/copyright). Absence of a point is not proof of absence of care. Straight-line distance is not travel time or access. Do not relabel an old archived extract as current. Keep source/derived database terms distinct from course prose. |
| `noaa_co2` | Fixed historical monthly Mauna Loa CO2 window, with original header, flags, trend, and seasonal fields. | [NOAA GML data and citation page](https://gml.noaa.gov/ccgg/trends/data.html), [monthly CSV](https://gml.noaa.gov/webdata/ccgg/trends/co2/co2_mm_mlo.csv). | `noaa_weather` | A fixed historical daily temperature/precipitation window for a few NOAA GHCN-Daily stations with station metadata and quality flags. | [NOAA GHCN-Daily](https://www.ncei.noaa.gov/products/land-based-station/global-historical-climatology-network-daily), [GHCN readme](https://www.ncei.noaa.gov/pub/data/ghcn/daily/readme.txt). Validate quality flags, missing days, instrument/location changes, and time coverage. Station observations and gridded NASA estimates are distinct products; comparisons require matched periods and locations. |
| `nasa_power` | A small fixed daily/monthly NASA POWER point subset of temperature, rainfall, and solar variables for the DRC climate context. | [NASA POWER API documentation](https://power.larc.nasa.gov/docs/services/api/), [NASA dataset citation guidance](https://doi.org/10.5067/DOC/ESCO/ESDS-RFC-055). Preserve spatial/temporal resolution and fill values. Check product-specific data terms; do not infer that every image or NASA logo is covered by data access guidance. |

| `usgs` | Earthquake catalog for a fixed past window, e.g. 2024 globally at magnitude >=4.5, with a smaller regional subset for 3D depth scenes. Record query, retrieval time, event IDs, magnitude types, depth/error fields, and units. | Catalog completeness and magnitude scales vary. Longitude/latitude order, UTC timestamps, and depth sign matter. Explain local projection and vertical exaggeration in 3D; negative-depth outliers need inspection, not silent clipping. Event occurrence is not a prediction of future hazard. |
| `natural_earth` | Pinned generalized country/coastline boundaries for small offline overview maps; U.S. county polygons require a separately documented Census geometry source. | [Natural Earth](https://www.naturalearthdata.com/), [public-domain terms](https://www.naturalearthdata.com/about/terms-of-use/). Credit "Made with Natural Earth"; record version, scale, CRS, simplification, and join keys. | Generalized boundaries are contextual and may be disputed. They are not precise legal boundaries or a substitute for a routing network. No claim that country centroids locate facilities or populations. |
| `phi_cholera` | A historical narrative and independently traceable aggregate table for the 1854 London cholera investigation. Reuse source records only after verifying their particular provenance/terms; otherwise link the case and use the other verified course datasets. | [PHI case review](phi-case-studies.md#cholera-browser-adaptation-and-basic-case), [PHI organization](https://github.com/PHI-Case-Studies). The reviewed JupyterLite cholera repository is GPL-3.0; retain that license if adapting covered code. Historical maps, digitizations, quotations, and later lesson text need separate checks. | Historical location reconstruction is uncertain. A map alone does not establish the causal argument. Do not copy modern map tiles, unlicensed scans, audio, contact details, or exercise patient line lists. This candidate is conditional and never blocks the verified-data core. |

## Snapshot contract

Every distributed dataset or derived artifact must have a manifest entry with:
provider and source page; exact query/download URL without credentials; release
and observation dates; UTC retrieval time; SHA-256 and byte/row counts; variable
definitions, units and missingness; CRS/geography and join keys; transforms and
input hashes; attribution, terms link and bundled notices; uncertainty and
known gaps. Validate a refresh before replacing the previous snapshot atomically.

The implementation must explicitly distinguish an observed measure, a modeled
estimate, a derived statistic, a source-documented relationship, and a teaching
scenario. Strategy diagrams may use assumptions to explore choices, but their
weights, capacities, utilities, forecasts, and causal links must be labeled and
accompanied by sensitivity analysis. None are measured outcomes simply because
an open dataset appears in the same lesson.

Keep the first-release teaching data compact: aim for <=25 MB total core data,
with per-file byte budgets in the manifest and optional imagery/model downloads
separate and user initiated. The initial Pyodide runtime itself has a larger
network cost; do not claim fully offline first launch. The browser's saved files
are user work: offer export and fresh release paths without erasing them.

Project-authored material remains without a newly selected project license.
Preserve each source's own terms. The final README must contain the citations
and attribution table itself, not only a link to this planning register.
