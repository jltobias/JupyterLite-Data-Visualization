# Proposed coverage of all 100 methods

Design dated 2026-10-28. Every row is a proposed substantial worked example,
not a claim of a completed or executed notebook. Source keys resolve in the
[data register](data-source-register.md). See the
[JSON matrix](100-element-coverage.json) for evidence classes and legacy crosswalk.

The inventory follows [Lengler and Eppler's framework](https://www.visual-literacy.org/periodic_table/periodic_table.html),
with normalized spelling and original course IDs. It does not reproduce the
poster, cell layout, illustrations, or hover examples. Strategy and process
methods often need an explicit teaching model: the source data provide context,
while invented weights, utilities, durations, causal links, and dialogue remain
clearly marked assumptions. Some methods require a critical discussion of their
suitability for public health rather than an unqualified recommendation.

Each implementation must include objectives, visible construction code, a source
table or evidence ledger, interpretation, an activity, limitations, and complete
attribution. Comparison views and keyboard-accessible text/table alternatives
are required. Group the course in six independently runnable family notebooks;
map/scene/story companions can be exported from the same data.
