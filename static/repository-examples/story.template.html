Below the map

A map places an earthquake. Time reveals a sequence. Depth changes the picture. Inspect 78 recorded events selected near Japan in January 2024, then ask what each view leaves out.

Locate the selection

The query selected magnitude ≥4.5 events between 30–46° N and 128–148° E, from January 1 inclusive to February 1 exclusive (UTC). These 78 epicenters are a bounded catalog selection. Overlap on a map does not establish a fault surface or predict another event.

What the story cannot establish

This is a selected catalog of revised events with mixed reported magnitude types. It does not include every earthquake, uncertainty ellipses, a completeness model, rupture geometry, an aftershock classification or a forecast. Clusters and apparent alignments require additional seismological evidence. Perspective, occlusion and vertical exaggeration change perception; compare the table and 2D view before interpreting a pattern.
